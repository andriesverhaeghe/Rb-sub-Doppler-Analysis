```
https://github.com/durham-qlm/scope2elecsus
```

## System Requirements

### Operating System

This project's package dependencies requires Windows 9+

### Dependencies

This project uses the UV package manager from Astral. Written in Rust, UV handles all dependencies in a virtual environment at blazing speeds, and doesn't even need a Python distribution to be installed on the machine to work. Installation steps can be found here:

```
https://docs.astral.sh/uv/getting-started/installation/
```

## Installation

The `pyproject.toml` file to this repo contains two packages whose linux wheels are very slow to install, and typically result in sync failures - wxpython and ElecSus (which depends on wxpython). To allow Github Actions to succeed as well as building and running of reduced functionality on Linux, these packages are optional dependencies. To install the core and dev dependencies run:

```
uv sync
```

To install only the core depencies (no dev dependencies or GUI) run:

```
uv sync --no-dev
```

To install everything, run:

```
uv sync --all-extras
```

## Running

### Main Pipeline

The main pipeline execution is invoked via the following uv command.

```
uv run pipeline <args>
```

This entrypoint accepts the following arguments to modify the pipeline execution.

- `--theory`: Enables ElecSus theory comparison
- `--example-data`: Runs the analysis on the example data (see below)
- `--select-points`: Enables overwriting of params using pyplot ginput

### Params

There are three project scripts relating to the saving and pulling of params generated by `pyplot.ginput`:

- `reset_defaults`: This returns all params to the original values found in the paper. This should be run before all PRs to prevent merge conflicts.
- `save_params`: This backs up all the current params into a git-ignored folder. Run this if you don't want `reset_defaults` to erase your progress.
- `pull_params`: Use this to pull the backed-up params back into the main folder read by the analysis pipeline.

All three of these scripts are run with:

```
uv run <script>
```

### Others

A utility script named `env` displays all the relevant packages in the current Python environment. Run with:

```
uv run env
```

## Example Data

As written in the scope2elecsus README.md:

- **Dopp_Broadened_20C.csv**: This is the raw data for the Doppler broadened spectrum at 20 degrees Celsius.

- **Dopp_Broadened_40C Norm.csv**: This is the normalised data for the Doppler broadened spectrum at 40 degrees Celsius.

- **Dopp_Broadened_73C Lin.csv**: This is the linearised data for the Doppler broadened spectrum at 73 degrees Celsius.

- **Dopp_Broadened_73C Norm.csv**: This is the normalised data for the Doppler broadened spectrum at 73 degrees Celsius.

- **Etalon.csv**: This is the raw data for the etalon, recorded simultanously with 'Dopp_Broadened_20C.csv' above.

- **Sub_Doppler Spectrum.csv**: This is the raw data for the sub-Doppler spectrum, recorded simultanously with 'Dopp_Broadened_20C.csv' above.
